4.4 OBSERVATIONS AND ROUTE COMPARISON
--------------------------------------
1. Common Local Path:
   All three routes traverse the exact same initial 3 hops:
   - Hop 1: Local Default Gateway (`172.16.8.1`) - latency < 1ms.
   - Hop 2: Campus Core / Aggregation Switch (`172.16.13.1`) - latency < 1ms.
   - Hop 3: ISP Border Router (`136.232.33.117`) - latency ~3ms.

2. Divergence:
   - Google traffic quickly routes into Google's direct peering edge (`72.14.243.188`) at Hop 6.
   - Facebook routes into Meta's autonomous system (`157.240.66.228`) at Hop 7.
   - BIT Mesra's site is protected by Sucuri Cloud WAF Anycast nodes, routing through international 
     transit carrier Arelion/Telia (`62.115.x.x`), increasing latency to ~160ms.
