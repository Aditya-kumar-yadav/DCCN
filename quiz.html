================================================================================

1.1 LAB NETWORK TOPOLOGY
-------------------------
In a typical computer networking laboratory, an **Extended Star Topology** (Hierarchical Tree) 
is implemented for optimal scalability, manageability, and fault isolation:

  [Internet / College Backbone WAN]
                 |
          [Core Router / Firewall]  <--- Default Gateway (Layer 3)
                 |
      [Distribution / Layer 3 Switch]
           /           \
  [Access Switch 1]   [Access Switch 2]  <--- Layer 2 Switches (Rack-mounted)
     |    |    |         |    |    |
    PC1  PC2  PC3       PC4  PC5  PC6   <--- Lab Workstations (Star topology)

- **Access Layer**: Unmanaged or managed Layer-2 switches connecting individual desktop 
  workstations via Category 6 (Cat6) UTP cables terminating in RJ-45 wall ports.
- **Distribution Layer**: Aggregates traffic from access switches and provides VLAN segmentation 
  (e.g., separate VLANs for Lab Systems, Faculty, and Servers).
- **Core Layer**: High-speed core router/firewall handling inter-VLAN routing, Network Address 
  Translation (NAT), traffic filtering, and uplink to the campus backbone.


1.2 LOCATING DIFFERENT NETWORK INTERFACES
-----------------------------------------
A network interface represents a node's physical or logical connection to the network.

A. Physical Interfaces:
   - **Ethernet (NIC)**: Identified as `eth0`, `enp3s0` (Linux) or `Ethernet 1` (Windows). 
     Contains a permanent hardware MAC address (48-bit / 6 octets, e.g., `50:7B:9D:4A:BC:12`).
   - **Wireless (Wi-Fi)**: Identified as `wlan0`, `wlp2s0` (Linux) or `Wi-Fi` (Windows).

B. Logical / Virtual Interfaces:
   - **Loopback (`lo`)**: IP `127.0.0.1/8` (`::1` in IPv6). Used for local inter-process communication 
     and diagnostic self-testing of the TCP/IP network stack without transmitting over physical media.
   - **Virtual Bridge/Tun/Tap**: Created by hypervisors or VPNs (`docker0`, `tun0`).

C. Commands to locate and inspect interfaces:
   - Windows: 
     > `ipconfig /all`     (Lists MAC address, IPv4/IPv6, subnet mask, DHCP server, DNS)
     > `getmac /v`         (Lists network adapter hardware MAC addresses)
     > `route print`       (Displays active IPv4/IPv6 routing table and gateway interfaces)
   - Linux:
     > `ip addr show` or `ifconfig -a`  (Lists all interfaces and assigned IPs)
     > `ip link show`                   (Shows state and MAC address)
     > `netstat -i`                      (Displays interface packet transmission statistics)


1.3 ROLE AND LOCATION OF ROUTERS AND SWITCHES
----------------------------------------------
A. Switches (Data Link Layer - OSI Layer 2):
   - **Location**: Mounted inside 19-inch lab server racks or wall-mount distribution boxes.
   - **Function**: Connects workstations inside the same Local Area Network (broadcast domain).
   - **Working Principle**: Inspects incoming Ethernet frame headers, builds a Dynamic MAC 
     Address Table (CAM table: Port <-> MAC), and forwards frames directly to destination ports 
     (micro-segmentation), eliminating collisions.

B. Routers (Network Layer - OSI Layer 3):
   - **Location**: Located in the central server/networking room at the lab perimeter.
   - **Function**: Connects distinct IP subnets (e.g., Lab LAN <-> Campus Backbone <-> Internet).
   - **Working Principle**: Reads Layer 3 IP headers, evaluates routing tables using longest-prefix 
     matching, decrements TTL (Time to Live), and routes packets across networks.
   - **Additional Services**: Runs DHCP server daemon to assign dynamic IP leases, NAT to translate 
     private lab IPs to public IPs, and Access Control Lists (ACLs) for security.


1.4 STUDYING DIFFERENT POOLS OF IP ADDRESSES
---------------------------------------------
IPv4 addresses are 32-bit identifiers split into standard classes and special functional pools:

A. Classful Addressing Overview:
   +-------+--------------------+--------------------+-----------------------+
   | Class | First Octet Range  | Default Subnet     | Purpose / Application |
   +-------+--------------------+--------------------+-----------------------+
   | A     | 1 - 127            | 255.0.0.0 (/8)     | Very large networks   |
   | B     | 128 - 191          | 255.255.0.0 (/16)  | Medium-sized networks |
   | C     | 192 - 223          | 255.255.255.0 (/24)| Small Local Networks  |
   | D     | 224 - 239          | N/A                | Multicast groups      |
   | E     | 240 - 255          | N/A                | Experimental/Reserved |
   +-------+--------------------+--------------------+-----------------------+

B. Private IP Address Pools (RFC 1918 - Non-routable on Public Internet):
   - Class A Private: `10.0.0.0` to `10.255.255.255`       (10.0.0.0/8    = 16,777,216 IPs)
   - Class B Private: `172.16.0.0` to `172.31.255.255`     (172.16.0.0/12 = 1,048,576 IPs)
   - Class C Private: `192.168.0.0` to `192.168.255.255`   (192.168.0.0/16= 65,536 IPs)
   *Note: Lab computers typically receive private IP addresses from either `172.16.x.x` or `192.168.x.x`.*

C. Special and Reserved IP Pools:
   - **Loopback Address Block**: `127.0.0.0/8` (e.g., `127.0.0.1` = localhost)
   - **APIPA (Automatic Private IP Addressing)**: `169.254.0.0/16` (assigned by OS when DHCP fails)
   - **Broadcast Addresses**:
     - Limited Broadcast: `255.255.255.255` (broadcasts to current local subnet)
     - Directed Broadcast: Host bits all 1s (e.g., `192.168.1.255` for `192.168.1.0/24`)
   - **Default Route / Any Network**: `0.0.0.0/0`

2.1 PING COMMAND USAGE AND OBSERVATIONS
----------------------------------------
A. Purpose:
   - Tests end-to-end IP network reachability between source and destination hosts.
   - Measures packet loss and Round-Trip Time (RTT) in milliseconds.

B. Underlying Protocol:
   - Uses **ICMP (Internet Control Message Protocol)** at Layer 3:
     1. Source transmits an **ICMP Echo Request** (Type 8, Code 0) packet.
     2. Target machine responds with an **ICMP Echo Reply** (Type 0, Code 0) packet.

C. Command Syntax and Key Flags:
   - Windows: `ping -n <count> -l <size_in_bytes> <host_or_ip>`
   - Linux:   `ping -c <count> -s <size_in_bytes> <host_or_ip>`
   - Example:
     > `ping -n 4 google.com`
     Outputs: Sent packets, received packets, lost packets (%), min/max/average RTT.


2.2 TRACEROUTE / TRACERT COMMAND USAGE AND OBSERVATIONS
--------------------------------------------------------
A. Purpose:
   - Maps the exact hop-by-hop path (list of intermediate Layer 3 routers) traversed 
     by an IP packet toward a target destination.
   - Diagnoses where packet loss, latency spikes, or network routing loops occur.

B. Underlying Mechanism:
   - Operates by manipulating the **TTL (Time to Live)** field in the IPv4 header:
     1. Source sends a probe packet with `TTL = 1`.
     2. The first router decrements TTL to 0, drops the packet, and sends back an 
        **ICMP Time Exceeded** message (Type 11, Code 0). The router's IP is recorded.
     3. The source increments TTL (`TTL = 2`, `TTL = 3`, ...) for subsequent probes.
     4. This continues until the probe reaches the target destination, which replies with 
        an ICMP Echo Reply (Windows tracert) or ICMP Port Unreachable (Linux traceroute UDP probe).

C. Command Syntax:
   - Windows: `tracert -d <destination>`  (-d avoids reverse DNS resolution for speed)
   - Linux:   `traceroute -n <destination>`


2.3 REMOTE LOGIN USING TELNET SESSION
--------------------------------------
A. Purpose:
   - Provides a bidirectional, interactive text-oriented communications facility using a 
     virtual terminal connection over a TCP/IP network.
   - Default Transport Port: **TCP Port 23**.

B. Usage / Syntax:
   - Initiating connection:
     > `telnet <remote_host_ip_or_hostname> <port>`
     Example: `telnet 192.168.1.100 23`
   - Testing connectivity to network application ports (e.g., HTTP / SMTP):
     > `telnet google.com 80`
     Type: `GET / HTTP/1.1` followed by two Enter keys to receive HTTP headers.

C. Security Vulnerability & Modern Alternative:
   - **Vulnerability**: Telnet transmits all data, including administrative usernames and 
     passwords, in completely **unencrypted plain text**, making it highly susceptible to 
     eavesdropping and Man-In-The-Middle (MITM) packet sniffing attacks.
   - **Modern Standard**: **SSH (Secure Shell, TCP Port 22)** has replaced Telnet. SSH 
     encrypts all payload and authentication traffic using strong cryptographic protocols 
     (RSA, ECDSA, AES).


2.4 MEASURING TYPICAL AVERAGE DELAYS ACROSS NETWORK LOCATIONS
--------------------------------------------------------------
A. Components of End-to-End Nodal Delay:
   Total Delay (d_nodal) = d_proc + d_queue + d_trans + d_prop
   - **Processing Delay (d_proc)**: Time router takes to examine packet header and determine route.
   - **Queuing Delay (d_queue)**: Time packet spends waiting in router buffer queues.
   - **Transmission Delay (d_trans)**: Time to push packet bits onto physical link (Packet Size / Bandwidth).
   - **Propagation Delay (d_prop)**: Time for a bit to physically travel down medium (Distance / Speed of Light in medium).

B. Typical Empirical Latency Profiles Measured:
   +------------------------------+---------------------------+---------------------------------+
   | Location / Segment           | Typical Round-Trip (RTT)  | Characteristic                  |
   +------------------------------+---------------------------+---------------------------------+
   | Localhost (Loopback)         | < 0.1 ms                  | Software stack only (no cable)  |
   | Same Lab Subnet (Switch)     | < 1 ms                    | Direct Layer 2 frame forwarding |
   | Campus Gateway / Core Router | 1 ms - 5 ms               | Layer 3 routing & NAT processing|
   | Regional / Domestic WAN      | 25 ms - 60 ms             | Fiber backbone across state     |
   | Overseas / International WAN | 130 ms - 260 ms           | Undersea intercontinental cables|
   +------------------------------+---------------------------+---------------------------------+

/*
 * IT302 DCCN Lab - Question 5
 * Program to determine whether an IPv4 address is in Class A, B, C, D, or E.
 */

#include <stdio.h>

int main(void) {
    char ip[32];
    int o1, o2, o3, o4;

    printf("Enter IPv4 Address (e.g. 192.168.1.1): ");
    if (scanf("%31s", ip) != 1) return 1;

    if (sscanf(ip, "%d.%d.%d.%d", &o1, &o2, &o3, &o4) != 4 ||
        o1 < 0 || o1 > 255 || o2 < 0 || o2 > 255 ||
        o3 < 0 || o3 > 255 || o4 < 0 || o4 > 255) {
        printf("Invalid IPv4 address format!\n");
        return 1;
    }

    printf("\n--- IP Classification Result ---\n");
    printf("IP Address : %d.%d.%d.%d\n", o1, o2, o3, o4);

    if (o1 >= 0 && o1 <= 127) {
        printf("Class      : Class A\n");
        printf("Subnet Mask: 255.0.0.0\n");
        printf("Network ID : %d.0.0.0\n", o1);
        printf("Host ID    : 0.%d.%d.%d\n", o2, o3, o4);
    } else if (o1 >= 128 && o1 <= 191) {
        printf("Class      : Class B\n");
        printf("Subnet Mask: 255.255.0.0\n");
        printf("Network ID : %d.%d.0.0\n", o1, o2);
        printf("Host ID    : 0.0.%d.%d\n", o3, o4);
    } else if (o1 >= 192 && o1 <= 223) {
        printf("Class      : Class C\n");
        printf("Subnet Mask: 255.255.255.0\n");
        printf("Network ID : %d.%d.%d.0\n", o1, o2, o3);
        printf("Host ID    : 0.0.0.%d\n", o4);
    } else if (o1 >= 224 && o1 <= 239) {
        printf("Class      : Class D (Multicast)\n");
    } else {
        printf("Class      : Class E (Experimental / Reserved)\n");
    }

    return 0;
}

Problem: 6. Write a C/C++ program to translate dotted decimal IP address into 32 bit address.
⚡ Key Concept: Converts dotted decimal IPv4 string (A.B.C.D) into a single 32-bit integer: (A<<24) | (B<<16) | (C<<8) | D. Prints full 32-bit binary representation, decimal integer, and Hexadecimal.

📄 Q6_Dotted_Decimal_To_32Bit.c 
/*
 * IT302 DCCN Lab - Question 6
 * Program to translate a dotted decimal IPv4 address into a 32-bit binary and integer address.
 */

#include <stdio.h>

void print_binary8(unsigned int n) {
    for (int i = 7; i >= 0; i--) {
        putchar((n & (1 << i)) ? '1' : '0');
    }
}

int main(void) {
    char ip[32];
    unsigned int o1, o2, o3, o4;

    printf("Enter IPv4 Address in dotted decimal (e.g. 192.168.1.1): ");
    if (scanf("%31s", ip) != 1) return 1;

    if (sscanf(ip, "%u.%u.%u.%u", &o1, &o2, &o3, &o4) != 4 ||
        o1 > 255 || o2 > 255 || o3 > 255 || o4 > 255) {
        printf("Error: Invalid dotted decimal address!\n");
        return 1;
    }

    unsigned int addr32 = (o1 << 24) | (o2 << 16) | (o3 << 8) | o4;

    printf("\n--- Conversion Results ---\n");
    printf("Dotted Decimal  : %u.%u.%u.%u\n", o1, o2, o3, o4);
    printf("32-bit Binary   : ");
    print_binary8(o1); putchar(' ');
    print_binary8(o2); putchar(' ');
    print_binary8(o3); putchar(' ');
    print_binary8(o4); putchar('\n');
    printf("Continuous Bits : ");
    print_binary8(o1); print_binary8(o2); print_binary8(o3); print_binary8(o4);
    putchar('\n');
    printf("32-bit Unsigned : %u\n", addr32);
    printf("32-bit Hex      : 0x%08X\n", addr32);

    return 0;
}

#include <string.h>

void char_stuff(const char *in, char *out) {
    int i = 0, j = 0;
    // Add Frame Header
    strcpy(out, "DLE STX ");
    j = (int)strlen(out);

    while (in[i] != '\0') {
        // Check for "DLE" token in data
        if (strncmp(&in[i], "DLE", 3) == 0 && (i == 0 || in[i-1] == ' ') && 
            (in[i+3] == ' ' || in[i+3] == '\0')) {
            strcpy(&out[j], "DLE DLE ");
            j += 8;
            i += 3;
            if (in[i] == ' ') i++;
        } else {
            out[j++] = in[i++];
        }
    }
    // Add Frame Trailer
    if (j > 0 && out[j-1] != ' ') out[j++] = ' ';
    strcpy(&out[j], "DLE ETX");
}

void char_destuff(const char *in, char *out) {
    int i = 0, j = 0;
    // Skip initial "DLE STX "
    if (strncmp(in, "DLE STX ", 8) == 0) {
        i = 8;
    }

    int len = (int)strlen(in);
    // Find where trailer " DLE ETX" begins
    int end_limit = len;
    if (len >= 8 && strcmp(&in[len - 8], " DLE ETX") == 0) {
        end_limit = len - 8;
    } else if (len >= 7 && strcmp(&in[len - 7], "DLE ETX") == 0) {
        end_limit = len - 7;
    }

    while (i < end_limit) {
        // If "DLE DLE" appears, destuff one "DLE"
        if (strncmp(&in[i], "DLE DLE", 7) == 0) {
            strcpy(&out[j], "DLE");
            j += 3;
            i += 7;
        } else {
            out[j++] = in[i++];
        }
    }
    // Trim trailing space if any
    while (j > 0 && out[j-1] == ' ') j--;
    out[j] = '\0';
}

/*
 * IT302 DCCN Lab - Question 10
 * Program to perform Error Detection and Correction using Hamming Code (7, 4).
 * 4 data bits (d1, d2, d3, d4) encoded into 7-bit codeword with 3 parity bits (p1, p2, p4).
 */

#include <stdio.h>

int main(void) {
    int data[4];      // d1, d2, d3, d4
    int code[8];      // 1-indexed: code[1] to code[7]
    int rx[8];        // received codeword
    int s1, s2, s4, error_pos;

    printf("--- Error Correction using Hamming Code (7, 4) ---\n");
    printf("Enter 4 data bits (separated by spaces, e.g. 1 0 1 1): ");
    for (int i = 0; i < 4; i++) {
        if (scanf("%d", &data[i]) != 1) return 1;
    }

    // Placing data bits at positions 3, 5, 6, 7
    code[3] = data[0]; // d1
    code[5] = data[1]; // d2
    code[6] = data[2]; // d3
    code[7] = data[3]; // d4

    // Calculating even parity bits at powers of 2: 1, 2, 4
    code[1] = code[3] ^ code[5] ^ code[7]; // p1 covers 1, 3, 5, 7
    code[2] = code[3] ^ code[6] ^ code[7]; // p2 covers 2, 3, 6, 7
    code[4] = code[5] ^ code[6] ^ code[7]; // p4 covers 4, 5, 6, 7

    printf("\n[Sender] Parity Bits: p1 = %d, p2 = %d, p4 = %d\n", code[1], code[2], code[4]);
    printf("[Sender] Transmitted 7-bit Codeword: ");
    for (int i = 1; i <= 7; i++) printf("%d", code[i]);
    printf("\n  (Bit order: p1 p2 d1 p4 d2 d3 d4)\n");

    // Receiver Simulation
    printf("\n[Receiver] Enter 7 received bits (separated by spaces): ");
    for (int i = 1; i <= 7; i++) {
        scanf("%d", &rx[i]);
    }

    // Calculate syndrome bits
    s1 = rx[1] ^ rx[3] ^ rx[5] ^ rx[7];
    s2 = rx[2] ^ rx[3] ^ rx[6] ^ rx[7];
    s4 = rx[4] ^ rx[5] ^ rx[6] ^ rx[7];

    error_pos = (s4 * 4) + (s2 * 2) + (s1 * 1);

    if (error_pos == 0) {
        printf("\n[Receiver] Status: NO ERROR DETECTED! Codeword is correct.\n");
    } else {
        printf("\n[Receiver] Status: ERROR DETECTED at bit position %d!\n", error_pos);
        rx[error_pos] = 1 - rx[error_pos]; // Correct the erroneous bit
        printf("[Receiver] Corrected Codeword: ");
        for (int i = 1; i <= 7; i++) printf("%d", rx[i]);
        printf("\n[Receiver] Recovered Data Bits: %d %d %d %d\n", rx[3], rx[5], rx[6], rx[7]);
    }

    return 0;
}

11.1 INTRODUCTION TO SOCKET PROGRAMMING
----------------------------------------
A socket is an endpoint for bidirectional, inter-process communication (IPC) across an 
IP network. A network socket is bound to a combination of an **IP Address** and a **Port Number** 
(e.g., `127.0.0.1:8080`).

Sockets operate in two primary modes:
1. **Stream Sockets (`SOCK_STREAM`)**: Based on TCP (Transmission Control Protocol). Connection-oriented, 
   reliable, ordered, and error-checked byte stream delivery.
2. **Datagram Sockets (`SOCK_DGRAM`)**: Based on UDP (User Datagram Protocol). Connectionless, 
   unreliable, minimal overhead, message-boundary preserving.


11.2 TCP CLIENT-SERVER ARCHITECTURE WORKFLOW
---------------------------------------------

         SERVER                                          CLIENT
   ------------------                             -------------------
     socket()                                           socket()
        |                                                  |
      bind()                                               |
        |                                                  |
     listen()                                              |
        |                                                  |
     accept()  <---------- [SYN: Connection Request] ---- connect()
        |     ---------- [SYN-ACK: Acknowledgment] ------->|
        |     <---------- [ACK: Connection Established] ---|
        |                                                  |
     recv()    <---------- [Data Request] ----------------- send()
        |                                                  |
     send()    ---------- [Data Response] ----------------> recv()
        |                                                  |
     close()   <---------- [FIN / Close] ------------------ close()


11.3 CORE SOCKET SYSTEM CALL PRIMITIVES (C API)
------------------------------------------------
1. `socket(int domain, int type, int protocol)`:
   - Creates an unbound network socket descriptor.
   - Example: `int fd = socket(AF_INET, SOCK_STREAM, 0);` (IPv4, TCP).

2. `bind(int sockfd, const struct sockaddr *addr, socklen_t addrlen)`:
   - Assigns a local IP address and port number to the socket.
   - Used by servers to listen on a well-known port.

3. `listen(int sockfd, int backlog)`:
   - Marks the socket as passive (ready to accept incoming client connections).
   - `backlog`: Maximum number of pending connections queued.

4. `accept(int sockfd, struct sockaddr *addr, socklen_t *addrlen)`:
   - Blocks until an incoming connection arrives.
   - Extracts first connection from queue and returns a NEW active connected socket descriptor.

5. `connect(int sockfd, const struct sockaddr *addr, socklen_t addrlen)`:
   - Invoked by the client to initiate the 3-Way TCP handshake with the server.

6. `send()` / `recv()` (or `write()` / `read()`):
   - Transmits and receives data buffers over the established TCP byte stream.

7. `close()` (or `closesocket()` on Windows):
   - Terminates socket connection and releases OS descriptor resources.

/*

 * Connects to an HTTP server over Port 80, requests a page, and saves the response.
 * Cross-platform: Compiles on both Windows (Winsock) and Linux (POSIX).
 */

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#ifdef _WIN32
  #include <winsock2.h>
  #include <ws2tcpip.h>
  #pragma comment(lib, "ws2_32.lib")
  #define CLOSE_SOCK(s) closesocket(s)
#else
  #include <sys/socket.h>
  #include <netinet/in.h>
  #include <arpa/inet.h>
  #include <netdb.h>
  #include <unistd.h>
  #define CLOSE_SOCK(s) close(s)
#endif

#define BUFFER_SIZE 4096

int main(void) {
#ifdef _WIN32
    WSADATA wsa;
    if (WSAStartup(MAKEWORD(2, 2), &wsa) != 0) return 1;
#endif

    char host[64] = "example.com";
    char path[128] = "/";
    int port = 80;

    printf("--- 12.1 HTTP Socket Web Page Download (GET) ---\n");
    printf("Target Host: %s, Port: %d, Path: %s\n", host, port, path);

    // 1. Resolve host
    struct hostent *server = gethostbyname(host);
    if (!server) {
        printf("Error: Could not resolve host %s\n", host);
        return 1;
    }

    // 2. Create Socket
    int sock_fd = socket(AF_INET, SOCK_STREAM, 0);
    if (sock_fd < 0) {
        perror("Socket failed");
        return 1;
    }

    struct sockaddr_in serv_addr;
    memset(&serv_addr, 0, sizeof(serv_addr));
    serv_addr.sin_family = AF_INET;
    memcpy(&serv_addr.sin_addr.s_addr, server->h_addr_list[0], server->h_length);
    serv_addr.sin_port = htons(port);

    // 3. Connect to HTTP server
    printf("Connecting to %s...\n", host);
    if (connect(sock_fd, (struct sockaddr *)&serv_addr, sizeof(serv_addr)) < 0) {
        perror("Connection failed");
        CLOSE_SOCK(sock_fd);
        return 1;
    }
    printf("[+] Connected to HTTP server.\n");

    // 4. Construct and Send HTTP GET Request
    char request[512];
    snprintf(request, sizeof(request),
             "GET %s HTTP/1.1\r\n"
             "Host: %s\r\n"
             "User-Agent: C-Socket-HTTP-Client/1.0\r\n"
             "Connection: close\r\n\r\n",
             path, host);

    send(sock_fd, request, (int)strlen(request), 0);
    printf("[+] HTTP GET Request sent:\n%s\n", request);

    // 5. Receive HTTP Response and Save to File
    FILE *fp = fopen("downloaded_page.html", "wb");
    char buffer[BUFFER_SIZE];
    int total_bytes = 0, bytes_received;

    printf("[+] Receiving HTTP Response...\n");
    while ((bytes_received = recv(sock_fd, buffer, sizeof(buffer), 0)) > 0) {
        if (fp) fwrite(buffer, 1, bytes_received, fp);
        total_bytes += bytes_received;
        // Print preview to console
        fwrite(buffer, 1, bytes_received, stdout);

        fclose(fp);
        printf("\n\n[+] Download Complete! Total bytes: %d\n", total_bytes);
        printf("[+] Saved web page to 'downloaded_page.html'.\n");
    }

    CLOSE_SOCK(sock_fd);

    WSACleanup();
#endif
    return 0;

    }

    // 3. Simulate DORA 4-way handshake
    printf("\n--- Simulating DHCP DORA Exchange ---\n");
    printf("1. [Client -> Broadcast] DHCP DISCOVER (Looking for DHCP Server from MAC %s)\n", mac);
    printf("2. [Server -> Client   ] DHCP OFFER    (Offering IP: %s)\n", ip_pool[free_idx].ip);
    printf("3. [Client -> Server   ] DHCP REQUEST  (Requesting lease for %s)\n", ip_pool[free_idx].ip);
    printf("4. [Server -> Client   ] DHCP ACK      (Confirmed IP Lease)\n");

    // Commit lease
    ip_pool[free_idx].allocated = 1;
    strncpy(ip_pool[free_idx].mac, mac, sizeof(ip_pool[free_idx].mac) - 1);

    printf("\n[+] Lease Granted successfully!\n");
    printf("    Assigned IP    : %s\n", ip_pool[free_idx].ip);
    printf("    Subnet Mask    : %s\n", SUBNET_MASK);
    printf("    Default Gateway: %s\n", DEFAULT_GATEWAY);
    printf("    DNS Server     : %s\n", DNS_SERVER);
    printf("    Lease Duration : %d seconds\n", LEASE_TIME);
}

void release_ip(const char *mac) {
    for (int i = 0; i < POOL_SIZE; i++) {
        if (ip_pool[i].allocated && strcmp(ip_pool[i].mac, mac) == 0) {
            ip_pool[i].allocated = 0;
            ip_pool[i].mac[0] = '\0';
            printf("\n[+] DHCP RELEASE received: IP %s released by MAC %s.\n", ip_pool[i].ip, mac);
            return;
        }
    }
    printf("\n[-] No active lease found for MAC: %s\n", mac);
}

/*
 * IT302 DCCN Lab - Question 15.1
 * Routing Table Implementation using Dijkstra's Shortest Path Algorithm
 * (Link State Routing Protocol - e.g. OSPF)
 */

#include <stdio.h>

#define MAX_NODES 10
#define INF 9999

int main(void) {
    int n, src;
    int cost[MAX_NODES][MAX_NODES];
    int dist[MAX_NODES];
    int visited[MAX_NODES] = {0};
    int next_hop[MAX_NODES];

    printf("--- 15.1 Dijkstra's Link-State Routing Table ---\n");
    printf("Enter number of routers/nodes (max %d): ", MAX_NODES);
    if (scanf("%d", &n) != 1 || n <= 0 || n > MAX_NODES) return 1;

    printf("Enter adjacency cost matrix (%d x %d, enter %d for no direct link):\n", n, n, INF);
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            scanf("%d", &cost[i][j]);
            if (i == j) cost[i][j] = 0;
        }
    }

    printf("Enter source router ID (0 to %d): ", n - 1);
    if (scanf("%d", &src) != 1 || src < 0 || src >= n) return 1;

    // Initialization
    for (int i = 0; i < n; i++) {
        dist[i] = cost[src][i];
        if (cost[src][i] != INF && i != src) {
            next_hop[i] = i; // Direct neighbor is initial next hop
        } else {
            next_hop[i] = -1;
        }
    }
    visited[src] = 1;
    dist[src] = 0;
    next_hop[src] = src;

    // Dijkstra's Algorithm
    for (int count = 1; count < n; count++) {
        int min_dist = INF, u = -1;

        // Pick unvisited node with minimum distance
        for (int i = 0; i < n; i++) {
            if (!visited[i] && dist[i] < min_dist) {
                min_dist = dist[i];
                u = i;
            }
        }

        if (u == -1 || min_dist == INF) break;
        visited[u] = 1;

        // Relax neighbors of u
        for (int v = 0; v < n; v++) {
            if (!visited[v] && cost[u][v] != INF && (dist[u] + cost[u][v] < dist[v])) {
                dist[v] = dist[u] + cost[u][v];
                next_hop[v] = next_hop[u]; // Next hop remains the same as that to reach u
            }
        }
    }

    // Display Routing Table for Source Router
    printf("\n============================================\n");
    printf("      ROUTING TABLE FOR ROUTER %d (OSPF)    \n", src);
    printf("============================================\n");
    printf(" Destination | Total Cost | Next Hop Router \n");
    printf("--------------------------------------------\n");
    for (int i = 0; i < n; i++) {
        if (dist[i] == INF) {
            printf("      %2d     |  UNREACH   |        --       \n", i);
        } else {
            printf("      %2d     |    %4d    |        %2d       \n", i, dist[i], next_hop[i]);
        }
    }
    printf("============================================\n");

    return 0;
}
